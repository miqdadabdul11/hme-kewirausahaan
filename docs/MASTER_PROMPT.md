# MASTER PROMPT FINAL

## HME KEWIRAUSAHAAN — ORDER & MANAGEMENT PLATFORM

Buat sebuah website resmi untuk **Sub Kewirausahaan Himpunan Mahasiswa Elektro (HME)** yang berfungsi sebagai platform penjualan dan pengelolaan pesanan.

Website ini bukan marketplace yang harus selalu aktif berjualan. Sistem harus dirancang untuk mendukung penjualan yang hanya dibuka pada waktu-waktu tertentu, misalnya ketika ada event, Open Order, kegiatan HME, atau periode penjualan produk tertentu.

Tujuan utama sistem:

1. Menggantikan proses pemesanan yang sebelumnya menggunakan Google Form.
2. Membuat proses pemesanan lebih terstruktur.
3. Memudahkan pengurus Kewirausahaan mengelola produk dan pesanan.
4. Mendukung produk Ready Stock maupun Pre-Order.
5. Menyediakan sistem target pesanan untuk produk Pre-Order.
6. Menyimpan data pesanan secara terstruktur.
7. Mengintegrasikan data dengan Google Sheets untuk kebutuhan administrasi dan pelaporan.
8. Menyediakan dashboard admin yang dapat digunakan oleh kepengurusan HME berikutnya tanpa perlu mengubah source code.

---

# 1. KONSEP UTAMA WEBSITE

Website memiliki dua sisi:

### CUSTOMER / PUBLIC
Dapat diakses siapa saja tanpa harus login. Customer dapat melihat produk, detail produk, status penjualan, melakukan pemesanan, dan order tracking.

### ADMIN
Admin adalah pengurus Sub Kewirausahaan HME. Admin WAJIB login sebelum dapat mengakses dashboard. Admin mengelola produk, order, open order, pembayaran, inventory, dan laporan.

*(Catatan: Master Prompt selengkapnya terdapat pada input pengguna sebelumnya, yang berfokus pada aturan bisnis, role, Open Order, Pre-order, Checkout, Google Sheets Sync, dst.)*
